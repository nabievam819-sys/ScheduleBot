📚 ScheduleBot
ScheduleBot — это Telegram-бот для хранения и управления расписанием занятий.
Бот позволяет добавлять занятия в базу данных, просматривать всё расписание, выбирать расписание по определённому дню недели и удалять ненужные занятия.
✨ Возможности
➕ Добавление занятия
📅 Выбор дня недели
📚 Добавление названия предмета
⏰ Добавление времени занятия
🚪 Добавление номера кабинета
📋 Просмотр всего расписания
🗓 Просмотр расписания по выбранному дню
🗑 Удаление занятия
💾 Хранение данных в SQLite
🔐 Хранение Telegram-токена в .env

🗄 База данных
Для хранения расписания используется SQLite.
Таблица schedule содержит следующие поля:
Поле
Описание
id
Уникальный идентификатор занятия
day
День недели
subject
Название предмета
time
Время занятия
room
Номер кабинета
🚀 Установка и запуск
1. Клонировать репозиторий
git clone ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ
Перейти в папку проекта:
cd ScheduleBot
2. Установить зависимости
pip install -r requirements.txt
3. Создать файл 
.env
Создать файл .env в корневой папке проекта.
Внутри указать токен Telegram-бота:
BOT_TOKEN=your_telegram_bot_token
4. Запустить бота
python bot.py
После запуска в терминале появится:
🤖 ScheduleBot запущен!
🤖 Команды
/start
Запускает бота и показывает главное меню.
/help
Показывает список возможностей бота.
📱 Главное меню
После запуска пользователь видит кнопки:
➕ Добавить занятие
📋 Всё расписание
📅 Расписание по дню
🗑 Удалить занятие
➕ Добавление занятия
При добавлении бот последовательно запрашивает:
День недели
Название предмета
Время
Кабинет
После заполнения всех данных занятие сохраняется в базе данных.
📅 Просмотр по дню
Пользователь может выбрать любой день недели:
Понедельник
Вторник
Среда
Четверг
Пятница
Суббота
Воскресенье
После выбора бот показывает занятия только этого дня.
🗑 Удаление
Бот показывает список сохранённых занятий.
Пользователь выбирает нужное занятие, после чего оно удаляется из базы данных.
🔐 Безопасность
Файл .env содержит секретный токен Telegram-бота и не должен публиковаться.
Поэтому .env добавлен в .gitignore.
Для других пользователей проекта предусмотрен файл .env.example:
BOT_TOKEN=your_telegram_bot_token_here
